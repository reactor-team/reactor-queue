# @reactor-team/queue-protocol

Shared wire protocol (message types + default tunables) for
[`@reactor-team/queue`](https://www.npmjs.com/package/@reactor-team/queue) and
[`@reactor-team/queue-server`](https://www.npmjs.com/package/@reactor-team/queue-server).

You usually don't depend on this directly — it comes in transitively. It has no
runtime dependencies and is safe to import in any environment.
